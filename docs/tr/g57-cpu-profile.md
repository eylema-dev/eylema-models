# G57 kendi CPU karar profili

Durum: sabitlenmiş model, bağımsız F64 referansı ve tek sınırlı Rust CPU kabul çağrısı geçti. Bu küçük, sabit smoke kümesidir; kalibre edilmiş kalite, geniş Türkçe kalite, genel kapasite veya performans kanıtı değildir. [İngilizce](../en/g57-cpu-profile.md).

Ayrı qwen3-reranker-0.6b.cpu kimliği G56 kaynak/artifact/tokenizer ve DecisionRoleInterface sözleşmesini korur; kendi F32 backbone ve F64 skaler normalizasyonumuzu kullanır. Özgün düz çift şablonu, son konum yes9693/no2152, yarım-çifte micros,750000eşik/100000fark ve çift başına reset kullanılır. Üretim, kalibrasyon veya eylem yetkisi yoktur. Özgün G56 metaverisi değişmez.

CPU JSON/EYL aynı core fixture ile koordineli kalır. Yetkilendirilen tek koşu 1.191.588.280 bayt artifact'ı `27cd75a405b9c1b46b59abfd88aaa209e6fed2a1972cde9b70e7659537c5e65b` SHA-256 ile doğruladı ve beklenen 310 tensorlu BF16 düzenini kabul etti. Bağımsız F64 oracle'a göre katman ve head mutlak farkları sırasıyla en çok 0,0005589494 ve 0,0000113805 oldu; donmuş değer başına sınır içindeydi. Dört çiftli/iki sorulu batch, sabit İngilizce ve Türkçe smoke girdilerinde önceden belirlenen pozitif seçeneği seçti; ters sıra eşleşti. Hesaplama ortası iptali batch sonucu döndürmedi. Toplam sayaçlı iş 956.151.402.665 birim; mantıksal tepe 1.361.720.300 bayt ve örneklenen RSS 905.183.232 bayt idi. Genel metadata ataması desteklenmez. Bu dar sonuçlar ilgi kalitesini, kalibrasyonu, geniş Türkçe kaliteyi, 4096 context kapasitesini, genel performansı, GPU'yu, eğitimi veya eylem yetkisini kanıtlamaz. Kaynak/profil/haklar e61197ed45024b0ed8a2d74b80b4d909f1255473 ve yayıncı README beyanına sabittir; proje/veri/aktarımı izni doğmaz. Tam CPU kabul kaydı kaynak deposunda eşli EN/TR belge olarak tutulur.
